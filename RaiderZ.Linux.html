คู่มือติดตั้ง Revolution RaiderZ (Non-Steam Game) บน Debian Trixie

ข้อมูลความเข้ากันได้ของระบบ:
  • ฮาร์ดแวร์ของคุณ (RX 580 / RAM 64GB) แรงทะลุความต้องการขั้นแนะนำของเกมนี้ไปไกลมาก
  • เนื่องจากเป็นตัวเกมนอกสโตร์หลัก (Private Server) จำเป็นต้องพึ่งพาเครื่องมือสแกนไฟล์เสริมเพิ่มเติม

ขั้นตอนที่ 1: ดาวน์โหลดและเตรียมไฟล์เกม

1เตรียมตัวติดตั้ง

  1. ดาวน์โหลดตัวเกมรันไทม์ของ Windows จากหน้าเว็บไซต์หลัก revolutionraiderz.com
  2. แตกไฟล์เกมทั้งหมดออกมา (ใช้รูปไฟล์ zip/rar ปกติ) แนะนำให้นำไปวางไว้ในโฟลเดอร์สำหรับเก็บเกมโดยเฉพาะ เช่น ~/Games/RevolutionRaiderZ เพื่อความเป็นระเบียบและสิทธิ์เข้าถึงไฟล์ที่ปลอดภัย

ขั้นตอนที่ 2: ติดตั้งและตั้งค่าเครื่องมือเสริม Protontricks

2เตรียมระบบแปลคำสั่งวินโดวส์

เนื่องจาก RaiderZ เป็นเกมเก่าที่พัฒนาบน DirectX 9 ระบบลินุกซ์จำเป็นต้องดาวน์โหลดส่วนเสริมมาใส่เพิ่ม โดยติดตั้งผ่านทาง Flatpak เปิด Terminal และกรอกคำสั่งดังนี้:

2.1 เปิดใช้งานระบบ Flatpak (หากยังไม่มี) และติดตั้ง Protontricks:

sudo apt update && sudo apt install flatpak -y
flatpak remote-add --if-not-exists flathub https://flathub.org
flatpak install flathub com.github.Matoking.protontricks -y

2.2 สร้างคำสั่งย่อ (Alias) เพื่อเรียกใช้งานโปรแกรมสะดวกขึ้น:

echo "alias protontricks='flatpak run com.github.Matoking.protontricks'" >> ~/.bashrc
source ~/.bashrc

ขั้นตอนที่ 3: เพิ่มเกมเข้า Steam และเปิดใช้ Proton

3การนำระบบภายนอกเข้าสู่คลังหลัก

  1. เปิดแอปพลิเคชัน Steam
  2. ไปที่เมนูด้านบน เลือก Games > คลิกที่ Add a Non-Steam Game to My Library...
  3. คลิกปุ่ม Browse เพื่อค้นหาไฟล์ในเครื่องของคุณ
  4. เข้าไปยังโฟลเดอร์เกมที่แตกไว้ในขั้นตอนแรก แล้วดับเบิลคลิกเลือกไฟล์ RaiderZLauncher.exe หรือ RaiderZ.exe จากนั้นกดปุ่ม Add Selected Programs
  5. ไปที่หน้าคลังเกม (Library) หาชื่อตัวเข้าเกมที่คุณเพิ่งเพิ่มเข้ามา คลิกขวาแล้วเลือก Properties...
  6. ไปที่หัวข้อ Compatibility ติ๊กเปิดเครื่องหมายถูกในช่องข้อความเพื่อบังคับใช้ระบบแปลงคำสั่ง แล้วเลือกเปลี่ยนเป็น Proton Experimental หรือ Proton 9.0
  7. สำคัญ กดรันเริ่มเกม (Play) สักหนึ่งครั้ง แม้ว่าเกมจะเปิดไม่ขึ้นหรือหน้าจอเงียบหายไป เพื่อปล่อยให้ Steam สร้างโฟลเดอร์ขวดระบบ (Prefix) ขึ้นมาก่อน

ขั้นตอนที่ 4: เติมส่วนประกอบที่ขาดด้วย Protontricks

4ติดตั้งไฟล์ DLL เพื่อแก้ปัญหาจอดำและเกมไม่รัน

  1. เปิดแอปพลิเคชัน Protontricks ขึ้นมาจากเมนูหลักของระบบปฏิบัติการ (หรือพิมพ์ protontricks --gui ใน Terminal)
  2. เลือกชื่อเกม RaiderZLauncher.exe (หรือชื่อตามที่คุณตั้งไว้ในคลัง) จากนั้นกด OK
  3. ในหน้าต่างถัดมา คลิกเลือกที่ Select the default wineprefix แล้วกด OK
  4. คลิกเลือกหัวข้อ Install a Windows DLL or component แล้วกด OK
  5. หน้าจอจะแสดงรายการซอฟต์แวร์เสริมของฝั่งวินโดวส์ ให้ค้นหาแล้วติ๊กเลือกหน้าช่องเหล่านี้:
    • 🔲 d3dx9 (ชุดประมวลผลกราฟิกและแสงเงาเก่า)
    • 🔲 vcrun2015 (ตัวรันระบบภาษาโค้ดซีพลัสพลัส)
  6. กดปุ่ม OK และปล่อยระบบให้ดาวน์โหลดติดตั้งไฟล์พื้นฐานเบื้องหลังจนเสร็จสิ้น
