🛠️ คู่มือแก้ไข initramfs.img เพื่อรองรับ F2FS

ทำตามขั้นตอนเหล่านี้บน Linux เครื่องอื่น (เช่น Ubuntu/Debian) เพื่อแตกไฟล์ ยัดโมดูล F2FS และแพ็กกลับคืน

⚠️ ข้อควรระวัง: การทำขั้นตอนเหล่านี้จำเป็นต้องใช้สิทธิ์ sudo เพื่อรักษาความเป็นเจ้าของไฟล์ (File Permissions) ในระบบจำลองให้ถูกต้อง มิฉะนั้นระบบที่บูทใหม่อาจจะพังได้
ขั้นตอนที่ 1: เตรียมพื้นที่ทำงานและคัดลอกไฟล์

สร้างโฟลเดอร์สำหรับทำงาน คัดลอกไฟล์ initramfs.img เดิมมาไว้ที่นี่

# สร้างโฟลเดอร์สำหรับแตกไฟล์
mkdir ~/workspace_initramfs
cd ~/workspace_initramfs

# คัดลอกไฟล์ initramfs ของ MiniOS มาที่นี่ (แก้พาธต้นทางให้ตรงกับของคุณ)
cp /path/to/your/initramfs.img .
ขั้นตอนที่ 2: แตกไฟล์ initramfs (Decompress)

สร้างโฟลเดอร์ปลายทางแล้วทำการแตกไฟล์อิมเมจออกมาด้วยคำสั่ง cpio

mkdir extract
cd extract

# แตกไฟล์ (กรณีส่วนใหญ่เป็น gzip)
zcat ../initramfs.img | sudo cpio -idmv

# หมายเหตุ: หากสั่ง zcat แล้วเออร์เรอร์ ให้ลองเปลี่ยนเป็น xzcat หรือ lz4cat ตามลำดับ
ขั้นตอนที่ 3: เพิ่มไดรเวอร์ F2FS (f2fs.ko)

นำไฟล์ไดรเวอร์ f2fs.ko ที่คอมไพล์ตรงกับเวอร์ชัน Kernel ของคุณ ไปวางในพาธโมดูลระบบ

# ตรวจสอบโครงสร้างโฟลเดอร์เวอร์ชัน Kernel ในโปรเจกต์ก่อน โดยพิมพ์:
ls usr/lib/modules/

# สร้างโฟลเดอร์เก็บไดรเวอร์ (แทนที่ [KERNEL_VERSION] ด้วยเลขเวอร์ชันที่พบ)
sudo mkdir -p usr/lib/modules/[KERNEL_VERSION]/kernel/fs/f2fs/

# คัดลอกไฟล์ไดรเวอร์เข้าไป (รวมถึง libcrc32c.ko ถ้าในระบบยังไม่มี)
sudo cp /path/to/f2fs.ko usr/lib/modules/[KERNEL_VERSION]/kernel/fs/f2fs/
ขั้นตอนที่ 4: สั่งให้ระบบโหลดโมดูล F2FS ตอนบูท

เปิดไฟล์สคริปต์หลักในการเริ่มต้นระบบ (มักเป็นไฟล์ชื่อ init อยู่ที่ Root ของโฟลเดอร์ที่แตกออกมา)

# เปิดไฟล์ init ด้วยโปรแกรมแก้ไขข้อความ
sudo nano init

ค้นหาจุดที่มีการสั่ง modprobe หรือ insmod แล้วเพิ่มคำสั่งโหลด f2fs ลงไปด้านบน ก่อนที่ระบบจะสั่ง mount พาร์ทิชัน:

# เพิ่มบรรทัดนี้ลงในตำแหน่งที่เหมาะสมในไฟล์ init
modprobe libcrc32c
modprobe f2fs

(กด Ctrl + O เพื่อบันทึก และ Ctrl + X เพื่อออกจาก nano)

ขั้นตอนที่ 5: บีบอัดและแพ็กไฟล์กลับคืน (Recompress)

เมื่อแก้ไขเสร็จแล้ว ให้ทำการสั่งแพ็กไฟล์ทั้งหมดกลับไปเป็นอิมเมจตัวใหม่

# ตรวจสอบว่ายังอยู่ในโฟลเดอร์ extract จากนั้นรันคำสั่งแพ็กไฟล์
sudo find . | cpio -H newc -o | gzip -9 > ../initramfs_f2fs.img

คุณจะได้ไฟล์ initramfs_f2fs.img อยู่ในโฟลเดอร์ ~/workspace_initramfs นำไฟล์นี้ไปเปลี่ยนชื่อแทนที่ไฟล์เดิมในแฟลชไดรฟ์หรือสื่อบันทึกข้อมูลของ MiniOS ได้เลยครับ
