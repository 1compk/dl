⚡ ขั้นตอนการแฟลช GSI ผ่าน Fastboot (Debian Trixie)

⚠️ คำเตือนความปลอดภัย: การดำเนินการนี้จะ ลบข้อมูลทั้งหมด ในแท็บเล็ต Alldocube iPlay 50 ของคุณ กรุณาสำรองข้อมูลสำคัญก่อนเริ่มทำ และตรวจสอบให้แน่ใจว่าแบตเตอรี่มีมากกว่า 50%

🛠️ ขั้นตอนที่ 1: ติดตั้งเครื่องมือบน Debian

เปิด Terminal บนระบบปฏิบัติการ Debian Trixie ของคุณ แล้วรันคำสั่งด้านล่างนี้เพื่อติดตั้งเครื่องมือควบคุมแอนดรอยด์:

sudo apt update
sudo apt install android-tools-adb android-tools-fastboot

🔓 ขั้นตอนที่ 2: ปลดล็อก Bootloader บนแท็บเล็ต

  1. ไปที่แท็บเล็ต: Settings > About Tablet > กดที่ Build Number ซ้ำๆ 7 ครั้งจนระบบแจ้งว่าเป็นผู้พัฒนาแล้ว
  2. ย้อนกลับไปที่ System > Developer options
  3. เปิดใช้งาน USB debugging และ OEM unlocking
  4. เสียบสายแท็บเล็ตเข้ากับคอมพิวเตอร์ Debian
  5. ใน Terminal บน Debian สั่งรีบูตเข้าโหมด Bootloader:
    6. adb reboot bootloader
  6. เมื่อหน้าจอแท็บเล็ตเข้าสู่หน้าดำๆ ให้พิมพ์คำสั่งปลดล็อกระบบ:
    7. fastboot flashing unlock
  7. ดูที่หน้าจอแท็บเล็ต: กดปุ่มปรับระดับเสียงเพื่อกดยืนยันการปลดล็อก (Confirm) ตัวเครื่องจะล้างข้อมูลและรีบูตใหม่

📦 ขั้นตอนที่ 3: เตรียมไฟล์ GSI (.img)

  1. หลังจากเครื่องรีบูตเสร็จ ให้เข้าไปเปิด USB Debugging ในเมนูผู้พัฒนาอีกครั้ง
  2. ดาวน์โหลดไฟล์ ROM GSI ที่ต้องการ (เช่น LineageOS GSI) นามสกุลไฟล์มักจะเป็น .img.xz
  3. แตกไฟล์บน Debian จนได้ไฟล์ชื่อ system.img
  4. ย้ายไฟล์ system.img เข้ามาไว้ในโฟลเดอร์ปัจจุบันที่ Terminal กำลังทำงานอยู่

⚡ ขั้นตอนที่ 4: เข้าสู่ Fastbootd (โหมดแฟลชระบบ)

  1. สั่งเข้าโหมด Fastboot ปกติก่อนด้วยคำสั่ง:
    2. adb reboot bootloader
  2. เมื่อเครื่องเข้าหน้าจอ Fastboot แล้ว ให้พิมพ์คำสั่งเพื่อสลับเข้าโหมด Fastbootd (โหมดของ Project Treble):
    3. fastboot reboot fastboot
  3. สังเกตหน้าจอแท็บเล็ต จะต้องเปลี่ยนเป็นหน้าเมนูสีๆ และมีคำว่า fastbootd อยู่ด้านบนสุด

💾 ขั้นตอนที่ 5: เริ่มกระบวนการแฟลช GSI

รันคำสั่งเหล่านี้ทีละแถวบน Terminal ของ Debian เพื่อเริ่มเขียนข้อมูล:

  1. ลบพาร์ทิชันเก่าที่ไม่ได้ใช้เพื่อเคลียร์พื้นที่ (แนะนำสำหรับชิป Unisoc):
    2. fastboot delete-logical-partition product
  2. แฟลชไฟล์ระบบ GSI ใหม่ลงไปแทนที่:
    3. fastboot flash system system.img
  3. ล้างค่าระบบโรงงานเพื่อป้องกันแอปเก่าตีกัน:
    4. fastboot -w
  4. รีบูตเครื่องเข้าสู่ ROM ใหม่ทันที:
    5. fastboot reboot
