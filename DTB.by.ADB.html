วิธีดึง DTB จากกล่อง Android TV ผ่าน ADB (บน Linux Trixie)

คู่มือนี้จะช่วยคุณดึงไฟล์ Device Tree Blob (DTB) จากกล่อง Android TV โดยตรงผ่านสาย USB หรือ Wi-Fi และแปลงเป็นซอร์สโค้ด (DTS) เพื่ออ่านโครงสร้างฮาร์ดแวร์

เตรียมความพร้อมที่ฝั่งกล่อง Android TV

เปิดใช้งาน USB Debugging
  • ไปที่กล่อง Android TV > การตั้งค่า (Settings) > ค่ากำหนดอุปกรณ์ (Device Preferences) > เกี่ยวกับ (About)
  • กดที่คำว่า หมายเลขบิวด์ (Build Number) ซ้ำๆ 7 ครั้ง จนระบบขึ้นว่าคุณเป็นนักพัฒนาซอฟต์แวร์แล้ว
  • ย้อนกลับมาที่เมนูก่อนหน้า เข้าไปที่ ตัวเลือกสำหรับนักพัฒนาซอฟต์แวร์ (Developer Options) แล้วเปิดใช้งาน การดีบัก USB (USB Debugging)

ขั้นตอนการทำบน Linux Trixie (Debian 13)

ขั้นตอนที่ 1: ติดตั้งเครื่องมือที่จำเป็น

เปิด Terminal บน Linux Trixie แล้วใช้คำสั่งนี้เพื่อติดตั้งเครื่องมือเชื่อมต่อและเครื่องมือแปลงไฟล์:

sudo apt update
sudo apt install adb device-tree-compiler source-highlight -y
ขั้นตอนที่ 2: เชื่อมต่อ ADB กับกล่อง

หากเชื่อมต่อผ่านสาย USB ให้เสียบสายได้เลย หรือหากเชื่อมต่อผ่าน Wi-Fi ให้ใช้คำสั่งระบุ IP ของกล่อง:

adb connect 192.168.1.XXX   # เปลี่ยนเป็น IP ของกล่องคุณ
adb devices                     # เช็คสถานะการเชื่อมต่อ (ต้องขึ้น device)

*อย่าลืมกด "ยอมรับการเชื่อมต่อ (Allow)" ที่หน้าจอทีวีหากมีป๊อปอัปเด้งขึ้นมา

ขั้นตอนที่ 3: รันสคริปต์ดึงและแปลงไฟล์อัตโนมัติ

คัดลอกกลุ่มคำสั่งด้านล่างนี้ไปวางใน Terminal เพื่อทำการดึงไฟล์ แปลงเป็นซอร์สโค้ด และจัดฟอร์แมตให้อ่านง่าย:

# 1. ดึงไฟล์ไบนารี fdt จากกล่องมาที่คอมพิวเตอร์
adb pull /sys/firmware/fdt ./extracted_dtb.dtb

# 2. แปลงไฟล์ไบนารีเป็นซอร์สโค้ดข้อความ (.dts)
dtc -I dtb -O dts -o android_box.dts extracted_dtb.dtb

# 3. แปลงซอร์สโค้ดให้เป็นหน้าเว็บ HTML ที่แยกสีโค้ดให้อ่านง่าย
source-highlight -i android_box.dts -o view_devicetree.html -s dts --out-format=html
ขั้นตอนที่ 4: เปิดอ่านโครงสร้างฮาร์ดแวร์

เมื่อรันเสร็จแล้ว คุณจะได้ไฟล์ใหม่ชื่อ view_devicetree.html โผล่ขึ้นมา ให้สั่งเปิดอ่านผ่านเว็บเบราว์เซอร์ด้วยคำสั่งนี้:

xdg-open view_devicetree.html
💡 คำแนะนำเพิ่มเติมสำหรับการอ่านโค้ด:
เมื่อเปิดไฟล์ view_devicetree.html บนเบราว์เซอร์ขึ้นมาแล้ว คุณสามารถกด Ctrl + F เพื่อค้นหาพาร์ตฮาร์ดแวร์ที่ต้องการได้ทันที เช่น:
  • ค้นหาคำว่า model = หรือ compatible = เพื่อดูข้อมูลรุ่นและชิปเซ็ตที่บอร์ดรองรับ
  • ค้นหาคำว่า wireless-wlan หรือ wifi เพื่อดูการตั้งค่าชิป Wi-Fi
  • ค้นหาคำว่า status = "okay" เพื่อดูว่าอุปกรณ์ส่วนไหนในกล่องถูกเปิดใช้งานอยู่บ้าง
