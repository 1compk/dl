คู่มือการเล่น Tom Clancy's The Division บน Debian Trixie (Steam/Proton)

สเปกเครื่องของคุณ:
  • CPU: Intel Core i5-13400F
  • RAM: DDR4 64GB
  • GPU: AMD Radeon RX 580 VRAM 8GB
  • Storage: NVMe 512GB
  • OS: Debian Trixie (Testing)

ขั้นตอนการตั้งค่าระบบและตัวเกม

1เปิดใช้งานคลังซอฟต์แวร์แบบ Non-Free

เปิด Terminal แล้วเปิดใช้งานสถาปัตยกรรมแบบ 32-bit พร้อมติดตั้งไดรเวอร์และเฟิร์มแวร์กราฟิกสำหรับ AMD ขาดไม่ได้สำหรับ Linux Gaming:

sudo dpkg --add-architecture i386
sudo apt update
sudo apt install firmware-amd-graphics mesa-vulkan-drivers libglx-mesa0:i386 mesa-vulkan-drivers:i386

2ติดตั้ง Steam และเปิดใช้งาน Steam Play (Proton)

ติดตั้ง Steam ผ่าน Apt Command:

sudo apt update && sudo apt install steam

เมื่อเข้าโปรแกรม Steam ให้เปิดใช้งานระบบแปลงคำสั่งเกมวินโดวส์ดังนี้:

  • ไปที่เมนู Steam (มุมซ้ายบน) > Settings
  • เลือกหัวข้อ Compatibility ด้านซ้ายมือ
  • ติ๊กเปิดใช้งาน "Enable Steam Play for supported titles"
  • ติ๊กเปิดใช้งาน "Enable Steam Play for all other titles"
  • ในช่อง "Run titles with:" ให้เลือกเป็น Proton Experimental หรือ Proton 9.0

3ติดตั้ง รันไทม์ระบบป้องกันการโกงเกม (Proton Anti-Cheat Runtimes)

สำคัญมากสำหรับโหมดออนไลน์:

เพื่อป้องกันไม่ให้ระบบเซิร์ฟเวอร์เตะคุณออกจากห้อง (โดยเฉพาะเวลาเข้าสู่ Dark Zone) ให้ติดตั้งตัวช่วยแปลระบบ Anti-Cheat บนเครื่องของคุณดังนี้:

  • ไปที่คลังเกมของคุณบน Steam (Library)
  • ตรงช่องค้นหาด้านซ้าย ให้พิมพ์คำว่า Proton Anti-Cheat หรือ Proton Runtime
  • ค้นหาและกด Install (ติดตั้ง) สองซอฟต์แวร์นี้:
    1. Proton EasyAntiCheat Runtime
    2. Proton BattlEye Runtime

4การตั้งค่า Launch Options ก่อนเริ่มเกม

การเปิดเกมครั้งแรก ตัวเกมจะเรียกใช้ตัวเปิดเกมของค่าย Ubisoft (Ubisoft Connect) เพื่อลดอาการค้างและช่วยให้เฟรมเรตนิ่งขึ้นบนการ์ดจอของคุณ:

  • คลิกขวาที่ชื่อเกม Tom Clancy's The Division ในคลัง Steam > เลือก Properties...
  • ในแถบ General มองหาช่อง Launch Options ด้านล่างสุด
  • พิมพ์คำสั่งต่อไปนี้ลงไปในช่อง:
GAMEMODE_GE_PROTON=1 %command%

5การตั้งค่าภายในเกม (In-Game Graphics Settings)

สำหรับหน่วยประมวลผลกราฟิก AMD RX 580 ให้ตั้งค่าในเกมเพื่อความลื่นไหลระดับ 60 FPS:

  • Resolution: 1920x1080
  • V-Sync: Off
  • Graphics Quality: Custom (ปรับแต่งเองโดยเริ่มจากพรีเซต Medium)
  • Shadow Quality: Medium
  • Object Detail: 40% - 50%
  • Anisotropic Filtering: 8x
  • Temporal AA: Stabilization
ข้อควรระวังพิเศษสำหรับระบบ Linux:
ในหน้าเมนูกราฟิกของเกม ห้ามเปิดใช้งาน DX12 (ต้องปรับ DX12 Renderer เป็น Off หรือใช้ DX11 เท่านั้น) เนื่องจากฟังก์ชัน DX12 ของตัวเกมภาคแรกนี้ ไม่เข้ากับระบบ Proton และจะทำให้เกิดอาการเกมค้างหรือหน่วยความจำล้น (Memory leak)
