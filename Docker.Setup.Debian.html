ใบความรู้ประกอบการเรียน

ขั้นตอนการติดตั้ง Docker บน Debian 13 (Trixie)

วิธีการติดตั้ง Docker Engine และ Docker Compose ผ่าน Official Repository อย่างถูกวิธี

OS: Debian Trixie

คำแนะนำสำหรับนักเรียน

คำสั่งทั้งหมดจำเป็นต้องใช้สิทธิ์ผู้ดูแลระบบ (root) หรือรันผ่านคำสั่ง sudo โปรดตรวจสอบให้แน่ใจว่าเครื่องคอมพิวเตอร์เชื่อมต่ออินเทอร์เน็ตอยู่ก่อนเริ่มทำตามขั้นตอน

1

ลบ Docker เวอร์ชันเก่าออกจากระบบ

ป้องกันปัญหาไฟล์ระบบชนกัน โดยลบแพ็กเกจเดิมที่อาจติดมากับดิสโทรออกก่อน

sudo apt remove docker docker-engine docker.io containerd runc
2

อัปเดตดัชนีแพ็กเกจและติดตั้ง Dependencies

ติดตั้งเครื่องมือจำเป็นสำหรับการดาวน์โหลดและยืนยันคีย์ความปลอดภัยจากเครือข่าย

sudo apt update
sudo apt install -y ca-certificates curl gnupg
3

เพิ่ม Docker's Official GPG Key

เป็นการลงทะเบียนคีย์สำหรับเข้ารหัส เพื่อให้ระบบตรวจสอบได้ว่าเป็นแพ็กเกจแท้จาก Docker จริงๆ

sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://docker.com | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
4

เพิ่ม Docker Repository สำหรับ Debian Trixie

สั่งเพิ่มแหล่งดาวน์โหลดซอฟต์แวร์ของ Docker ลงในระบบ APT โดยคำสั่งนี้จะตรวจจับสถาปัตยกรรมเครื่องและโค้ดเนมให้อัตโนมัติ

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://docker.com \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
5

ติดตั้ง Docker Engine และ Compose Plugin

อัปเดตรายการซอฟต์แวร์ใหม่อีกครั้ง จากนั้นรันคำสั่งดาวน์โหลดตัวโปรแกรมหลักของ Docker และเครื่องมือ Compose

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
6

ทดสอบรันคอนเทนเนอร์แรก

พิมพ์คำสั่งนี้เพื่อดึงคอนเทนเนอร์ขนาดจิ๋วมาทดสอบระบบ หากขึ้นคำว่า "Hello from Docker!" แสดงว่าติดตั้งเสร็จสมบูรณ์

sudo docker run hello-world

💡 ทริกเด็ด: ใช้งาน Docker โดยไม่ต้องพิมพ์ sudo

โดยปกติระบบจะล็อกไม่ให้ผู้ใช้ธรรมดารันคอนเทนเนอร์ ถ้านักเรียนไม่อยากพิมพ์ sudo ทุกครั้ง ให้พิมพ์คำสั่งด้านล่างนี้

sudo usermod -aG docker $USER

* หลังจากรันคำสั่งนี้แล้ว ให้นักเรียนล็อกเอาต์ออกจากเครื่อง (หรือปิด Terminal) แล้วเปิดใหม่เพื่อให้สิทธิ์อัปเดตทำงาน
